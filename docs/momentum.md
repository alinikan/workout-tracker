# Momentum

**Home gym now. One confirmed trial when you are ready.**

Momentum is the optional, single-owner coaching space inside Recomp. Its 90-day home routine
supports repeatable strength training, batch meals and recovery. Titan Training Centre is the
chosen venue for one optional trial, not an assumed weekly commitment. No trial date, weekday,
time, room or recurring class is assumed.

## Three Destinations

| Destination | What Happens Here |
| --- | --- |
| **Today** | One activity and one primary action. Follow a home session or open the Titan row to plan one visit. |
| **Meals** | Eat today / Cook batch / To buy. One main dish covers lunch and dinner for 2-3 days; cooking quantities and groceries are shared with Nutrition. |
| **Journey** | Seven days at a time, actual attendance, workload feedback and the shared kg weight trend. |

Settings contains pause, resume, repeat-week and shared Start Fresh controls. During a session,
navigation stays out of the way. Safe areas, reduced motion, touch controls and light/dark themes
are exercised in browser tests. These checks supplement, not replace, a physical-iPhone check.

## Start Whenever You Want

Choose today or a future date and **Start my 90 days**. Opening the app does not start it.
If Coach already has a shared Start Fresh date, onboarding uses that exact date instead.
Day 1 is Home Strength A even when the start is not Monday. There is no default trial.

### One Start Fresh Across The App

Open **Coach settings → Start fresh**, choose a date, type `RESET` and confirm. Momentum settings
opens the same confirmation. Read it carefully: shared workout, meal and weigh-in history is
cleared. Your account stays signed in. The former private Momentum journey and its private food
records are archived. Week 1 begins with no old trial, pauses or completion checks carried over.

The root progress row saves first; Momentum acknowledges the same reset generation afterward.
Keep the app open until the pending notice clears. Reconnecting devices adopt one deterministic
journey, rather than creating duplicates or restoring an older active journey.

**Installing this update does not perform Start Fresh.** Existing 30-day and Titan journeys adopt
the home plan while keeping IDs, starts, actual activity, meals and reviews. Past or partly worked
slots retain their original prescription. Unperformed upcoming automatic class assumptions are
cleared because the trial needs rescheduling. Short calendars extend to 90 days. This adoption is
idempotent: reopening does not repeatedly migrate or reset anything.

## Home Rhythm

The cycle is relative to your chosen start, not hardcoded weekdays.

| Cycle Day | Activity | What To Do |
| --- | --- | --- |
| 1 | Home Strength A | 5-7 easy warm-up minutes, clearly lighter practice of the first two lifts, then two comfortable working sets per movement. |
| 2 | Easy walk | Conversational movement; shorten it or rest if needed. |
| 3 | Recovery | No required workout. |
| 4 | Home Strength B | Same structure, with direct triceps instead of the A-day biceps exercise. |
| 5 | Easy walk | Comfortable movement and regular meals. |
| 6 | Recovery | No required workout. |
| 7 | Plan next week | Check your schedule and batch meals; no training test. |

The first two cycles contain four home lifts and no class unless you add one. Both strength days
use a wall sit (A) or small-range reverse Nordic (B), the fixed-arm machine chest press, supported dumbbell row, glute bridge and dead
bug. A adds cable curls; B adds cable pressdowns. Machine/cable work comes before floor work to
avoid travelling upstairs and downstairs repeatedly.

Use the documented setup and a secure bench for the row; never improvise unstable equipment.
The home plan does not assume a dedicated leg-extension machine or a usable Mi6 seated row. The bodyweight quad movements have a seated alternative if knee bending or kneeling is uncomfortable; recorded old machine sessions stay historical. No forced
squat or leg press is required. Exact existing exercise media and cues are reused. Weights are in
**lbs**. Keep comfortable range, controlled technique and several reps available; no maximum test
or training to failure is required.

### Progress Comes From Practice

The home plan begins with two working sets. A smaller session is always available. Another
calendar month does not automatically add sets, load or classes. Actual comfortable practice,
effort and recovery inform feedback; unknown recovery is not silently marked good. Walks may
grow after repeated comfortable walks. Workout's history-based Smart Load suggestions remain
optional, not instructions to increase a pin simply because time passed.

The connected Workout plan earns a training week after **two fully completed home lifts**:
52 for 26 earned weeks. Missed calendar weeks earn no credit. Its calendar continues beyond the
initial 90 days with the home routine, not the former three-lift schedule. Momentum attendance
stays separate from Workout attendance; checking one does not duplicate checks in the other.
The original standalone program retains its three-lift/78-total rules.

Journey phase names describe the calendar, not an intensity increase. Repeating a week can extend
the calendar. No missed activity creates a debt or compulsory catch-up session.

### A Session, Start To Finish

1. Read Today and press **Start session**. Strength shows one movement at a time.
2. Record actual reps and optional load. Check performed sets only. Previous/Next changes the view,
   not attendance. Returning selects the first unfinished movement.
3. **Review session**, or **Finish with what I did**. Full completion requires every required
   actual set. Smaller lifts need actual work; participating walks/classes need actual minutes.
4. Effort and comfort are short optional feedback. Update recovery later when you know it.
5. A saved result confirms the outcome. **Edit result** keeps performed sets when reopening.

Stop if you feel faint or develop concerning symptoms. A stopped session is not full completion
and does not permanently lock the account.

## One Flexible Titan Trial

1. Confirm a visit with the coach first. Open **Titan row → Trial date** and choose today or a
   future date within the active journey. Set the optional time only when known.
2. Read the week preview and press **Save trial date**. The preview itself changes no records.
3. The trial **replaces** that date's workout. The next day becomes recovery; a lift immediately
   before becomes easy movement. No displaced lift is squeezed into another day.
4. Workout Today, Gym, Week, Nutrition and Momentum derive the same scheduling change. Trial-day
   food uses training portions for uncooked batches and timing guidance, not duplicate meals.
5. Save a different date to reschedule, or **Remove trial date**. Unperformed dates return to the
   home routine. Actual/partly performed work cannot be repurposed. A performed visit is locked
   as history; a missed visit can be rescheduled. Reminder export needs a confirmed time.
6. After the visit, home training continues until you deliberately make a new plan. There is no
   automatic weekly class, promotion, sparring unlock or membership purchase.

The day-before/day-after buffer is a conservative product rule for an unfamiliar class, not a
validated personal recovery prescription. Actual recovery and coach guidance matter.
[Earlier membership research](titan-membership.md) is a dated reference, not live availability or
an instruction to buy. Nothing here books, cancels or pays Titan on your behalf.

## Meals And Weight

Momentum and Nutrition share a rolling **two-day or three-day batch plan**: one main dish covers
lunches/dinners, with repeated breakfast jars and yogurt/fruit snacks. Chicken breast, skinless
thighs and extra-lean beef with rice/potatoes and vegetables are the main rotation. See the
[batch-cooking guide](meal-prep.md) for ingredients, raw/dry versus cooked weights, container
portions, storage and reheating.

The home/trial schedule supplies training versus rest context. Logged kg weights inform bounded
protein portions. Changing a trial updates uncooked quantities and groceries; **already-cooked
containers and eaten meals keep saved portions**. Missed workouts do not trigger compensatory
food removal. Estimates are not measured personal energy needs.

Trial-date guidance suggests a familiar main meal about 3-4 hours before, or a smaller meal/snack
1-3 hours before. Use the planned snack, not a second full meal. Morning appointments get morning-
aware labels. Keep water available and take breaks. Food cannot guarantee you will not feel faint.

Shared batch choices, preparation and groceries live in `workout_progress` JSON. Momentum's eaten
checks, recipe IDs and portions remain private, separate from Diet history. **Coach Hub is the
single kg weigh-in entry point**; Journey displays that trend with honest missing-day coverage.

## Supabase: Existing Installations

**This release needs no new SQL, keys or reset.** Optional JSON fields use existing document schema
version 2, one-owner access and the revisioned save function. Permissions do not change.

Only installations missing the earlier shared-start update need
[`20261026_shared_start.sql`](../supabase/migrations/20261026_shared_start.sql) in
**SQL Editor → New query**. This function-only migration preserves records, revisions, grants,
RLS and the owner allowlist. It validates reset metadata against the owner's root record. Current
full setup migrations already include it. Vercel does not run database SQL.

### First-Time Private Setup

Use the same Supabase project/authentication as Recomp. Never put a service-role key or owner UID
in a `VITE_` variable or public repository.

1. Run `supabase/migrations/20261023_momentum.sql` as an administrator in **SQL Editor → New query**.
2. Find the intended account's **Authentication → Users → User UID**.
3. Run this privately, replacing the placeholder. Do not commit the finished query:

```sql
insert into momentum_private.momentum_owner (singleton, user_id)
values (true, 'REPLACE_WITH_YOUR_AUTH_USER_UUID'::uuid)
on conflict (singleton) do update set user_id = excluded.user_id;
```

4. Sign into that account and open **Coach Hub → Momentum**. Others see no entry.
5. Older installations should apply the existing setup/shared-start function revisions as needed.

To revoke, an administrator deletes the matching allowlist row, not the auth user or original
progress table. Offline devices discover revoked access only when reconnecting.

### Privacy And Sync Architecture

| Boundary | Protection |
| --- | --- |
| Discovery/reads | `momentum_access()` and owner/allowlist RLS, not public-code email checks. |
| Writes | `momentum_save()` derives the owner from `auth.uid()`, locks the row and compares revisions. Direct browser table writes are denied. |
| Multiple devices | Three-way merge preserves independent edits. Trial date/time is one atomic choice; timestamped cancellation prevents stale-device resurrection. |
| Device drafts | AES-GCM ciphertext with account-bound authentication data; the key stays in tab session storage. |
| Account changes | Owner checks, epochs, memory clearing and cache removal prevent cross-account private views. |
| Service worker | Caches shell assets, never private API responses. Versioned updates refresh installed app copies. |

> [!WARNING]
> Sync before closing an offline session: closing can discard the encryption key and make an unsynced
> draft unrecoverable. Server records remain available. Encryption does not protect a compromised
> device or malicious same-origin script. Update/reopen old app copies before editing new plans.

## Run, Test And Deploy

```bash
npm install
npm test
npm run test:ui -- --trial-only
npm run test:ui -- --momentum-only
npm run test:ui -- --shared-start-only
npm run test:ui -- --repeat=2
npm audit --audit-level=high
git diff --check
npm run dev -- --host 0.0.0.0 --port 3000
```

Use another port if occupied. Localhost supports private encryption; iPhone plain LAN HTTP does
not provide the secure context private drafts need. Use HTTPS Vercel for the Home Screen app and
the same authorized account on each device. Push reviewed changes to the linked production branch,
confirm GitHub checks and Vercel both succeed, then reopen the app. Do not clear browser data.

## Evidence And Limits

This is adherence-focused product design, not a validated personal prescription or promise of
a body transformation. Exact starting sets, buffers and feedback thresholds are product choices;
research supports the broader direction, not these exact personal numbers.

- [ACSM 2026](https://acsm.org/resistance-training-guidelines-update-2026/): consistent individualized resistance practice and useful home equipment; unnecessary complexity is not required.
- [CDC activity guidance](https://www.cdc.gov/physical-activity-basics/adding-adults/what-counts.html): strengthen major muscle groups at least twice weekly and build activity gradually.
- [Mayo Clinic eating and exercise](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/exercise/art-20045506): meal-size-dependent timing, familiar food and hydration.
- [NIDDK getting active](https://www.niddk.nih.gov/health-information/weight-management/tips-get-active/tips-starting-physical-activity): manageable beginnings and gradual increases.

Dates alone do not earn intensity. A routine you can repeat matters more than reaching day 90
with a harder plan you never practiced.
